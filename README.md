# Bloons TD Battles — Python Edition (Full Authentic Recreation)

نسخة متكاملة مبنية من الصفر تحاكي لعبة **Bloons TD Battles** الأصلية بدقة، باستخدام الأصول والرسوميات والأصوات المستخرجة عبر الهندسة العكسية من ملفات اللعبة بواسطة **REA**.

---

## ✨ المميزات المضافة حديثاً:

1. **الواجهة الرئيسية الأصلية (Main Menu)**:
   - خلفية البحر والغيوم المتحركة وسفينة الـ Buccaneer المتمايلة.
   - شعار اللعبة الرسمي العائم بتأثير متموج سلس.
   - أزرار البدء السريع، دليل التحكم، والخروج.

2. **الأصوات الأصلية بالكامل (Official Sounds)**:
   - أصوات فرقعة البالونات الحقيقية المتعددة (`pop1.wav`, `pop2.wav`, `pop3.wav`, `pop4.wav`).
   - أصوات بناء الأبراج، ترقيتها، وبيعها (`tower_place.wav`, `upgrade.wav`, `sell_tower.wav`).
   - صوت انفجار القنابل وتفتت الشظايا (`explosion_small.wav`).
   - أصوات ضرب البالونات الخزفية والمعدنية ومناطيد الـ MOAB (`ceramic_bloon_hit.wav`, `metal_bloon_hit.wav`, `moab_damage_quieter.wav`).
   - أصوات الفوز والهزيمة والنقر على الواجهات (`game_win.wav`, `game_over.wav`, `button_click.wav`).

3. **الضربات والمقذوفات وتأثيرات الانفجار (Combat & FX)**:
   - قنابل الـ Bomb Tower الأصلية مع تأثير انفجار حركي متعدد الإطارات (`explosion_01` إلى `explosion_05`).
   - مسامير وشفرات الـ Tack Shooter الحقيقية.
   - أشعة ليزر وبلازما للـ Super Monkey.

4. **خرائط وتضاريس ساحة المعركة (Authentic Map)**:
   - تضاريس خريطة `battle_sands` الصحراوية الرسمية المستخرجة كأرضية لساحة الدفاع.
   - أشرطة التحكم السفلية المعدنية الأصلية (`lower_hud_bg.png`).

5. **أشكال البالونات ومناطيد الـ MOAB**:
   - منطاد الـ MOAB الضخم بشكله الرسمي مع شريط نقاط الحياة.
   - بالونات السيراميك والمعدن ومختلف الطبقات الملونة الأصلية.

### أزرار التحكم أثناء اللعب:
- `1`, `2`, `3`, `4`: اختيار وبناء الأبراج.
- `Q`, `W`, `E`, `R`, `T`, `Y`, `U`, `I`: إرسال هجمات البالونات للخصم لرفع الدخل (Eco).
- النقر على أي برج لترقيته أو بيعه.
- `SPACE`: إيقاف / استئناف مؤقت.
- `ESC`: العودة للقائمة الرئيسية أو إلغاء التحديد.
